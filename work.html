rentive.pk (opens in a new tab)

Rentive

Property-management SaaS

A full-featured platform for landlords, property managers, and real-estate companies: rental properties, tenants, rent collection, and financial operations in one system, instead of a spreadsheet and a phone full of reminders.

  • Automated rent cycles with payment-status tracking, so collection runs on a schedule rather than on memory.
  • Tenant onboarding and property lifecycle management under a multi-role permission model — landlord, manager, and tenant each see their own system.
  • Real-time dashboards and financial reporting over every property's money trail.
  • React
  • Vite
  • Express.js
  • Node.js
  • MongoDB

Tejarify

B2B wholesale management platform

A custom, enterprise-grade platform that automates wholesale business operations — built from the ground up and deployed to the cloud for a business whose ledger used to live on paper.

  • Inventory, supplier tracking, and vendor credit managed in one record of truth.
  • Sales and purchase invoicing wired directly to financial transactions, so the books reconcile themselves.
  • Salary disbursement and business reporting layered over the same data — one platform for the whole operation.

03

Open source

Public work under github.com/devalinaqvi (opens in a new tab) — security tooling for the servers I run, plus contributions upstream. The newer tools are built agentically: AI coding agents write the code, while the specification, constraints, and every review are mine.

VPSentinel (opens in a new tab)

Go

A lightweight Linux/VPS security auditor: scans a host for network exposure and misconfiguration, and reports ranked, actionable findings. Ships as a single static Go binary — nothing to install on the box being audited.

  • Go
  • Linux

VPSentinel‑C++ (opens in a new tab)

C++

A read-only Linux and VPS security scanner: audits listening ports, SSH, sudo and privilege paths, filesystem permissions, exposed credentials, packages, Nginx/PHP/Laravel configuration, TLS, systemd, and firewall state — without changing anything it touches. Built entirely by directing AI coding agents: I wrote the spec and the audit checklist, set the guardrails, and reviewed every change.

  • C++
  • Linux
  • Agent-built

Attack Surface Mapper (opens in a new tab)

Python

Evidence-driven dependency capability maps for Composer: what your packages can actually do, why they were flagged, and the dependency path that introduced them. Runs fully offline — no package code is ever executed. Built with OpenAI Codex under my direction — prompt design, evidence rules, and verification of every finding by hand.

  • Python
  • Composer
  • OpenAI Codex

laravel‑pos (opens in a new tab)
