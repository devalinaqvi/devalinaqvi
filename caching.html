Caching: store, evict, and survive the stampede

Everyone caches. Fewer can say which strategy they are on, or what happens when a popular key expires.

The fastest query is the one you never make. That is the whole reason caching exists, and it is worth seeing the numbers before choosing a strategy.

Why caching exists at all

The gap between the fastest and slowest place you can read data is about eight orders of magnitude, and each step down costs roughly a hundred times the one above it:

L1 CPU cache        ~1 ns
main memory       ~100 ns
SSD random read    ~16 µs
same-datacentre   ~500 µs
disk seek           ~2 ms
cross-continent   ~150 ms

Caching is mostly the discipline of not descending a step you could have avoided.

Then choose how writes behave

Cache-aside writes to the database and lets the cache fill on read, so the first request for anything pays full price. Write-through updates both together, so reads are never stale and every write carries the cost. Write-behind writes to the cache and flushes later — the fastest option, and the one that loses data if the process dies before the flush. None is correct in general; they fail differently, and the job is picking the failure you can live with.

Then decide what to throw away

A cache with no eviction policy is a memory leak with better marketing. LRU evicts the least recently used entry, LFU the least frequently used, and a TTL evicts on a timer regardless. Most systems want a size bound and a TTL together.

And plan for the stampede

One hot key expires, ten thousand requests miss in the same millisecond, and the database gets its heaviest traffic at the moment it is least ready for it. Three fixes: jitter the TTL so keys do not expire together; use a single-flight lock so one miss does the refill while the rest wait; or serve the stale value while you refresh behind it.

The uncomfortable part underneath all of it: a cache is a second copy of your data with its own rules about when it is allowed to be wrong. Most cache bugs are that fact turning up unannounced.
